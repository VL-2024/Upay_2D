# UPAY 2D v0.1.4-alpha

Отдельная 2D-версия игры УПАЙ.

## Что добавлено в v0.1.4-alpha
- более естественный круговой разброс чуко вокруг Хана;
- стартовый разлёт чуко на поле;
- визуальный выбор чуко-биты;
- переработанный удар: замах, рывок, вспышка в точке контакта;
- лёгкий разлёт соседних чуко от удара;
- выбитый чуко по дуге улетает в слот УПАЙ;
- отдельная анимация неудачного последнего удара.

## Уже есть
- сценарный движок ZERO / ONE / TWO / KHAN / ALTYN;
- demo-режим по кругу;
- два поля УПАЙ по 3 ячейки;
- выбор ставки как в Чуко 20.72;
- текущая мобильная компоновка с фоном и ковром.

## Дальше
- инфопанель как в ORDO 20.72;
- автоигра;
- LMS-адаптер и реальные сценарии от backend.
