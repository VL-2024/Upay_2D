# UPAY 2D v0.1.21-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.21-alpha
- сохранено встроенное прицеливание: выбрать биту → оттянуть назад → отпустить;
- обычные чуко остаются увеличенными;
- декоративные цвета чуко теперь сохраняются и во время подсветки/выбора цели: бирюзовый, лазурный, фиолетовый, коралловый, салатовый;
- цвет выбитого чуко сохраняется в ячейке УПАЙ;
- центральная кнопка во время активного билета показывает «БРОСОК / УДАР», после завершения — «НОВАЯ ИГРА»;
- панель «Положения чуко» и подсветка Айкүр / Таа / Бөк / Чик сохранены.

## Правила
- обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- одинаковое положение бьёт одинаковое положение.

## Уже есть
- встроенное оттягивание и отпускание без конфликтующих overlay-скриптов;
- бьющий чуко летит к цели и после удара переворачивается в новое положение;
- подсветка допустимых целей;
- увеличенные чуко;
- цветные чуко;
- скрываемая панель положений;
- поля УПАЙ и сценарии ZERO / ONE / TWO / KHAN / ALTYN.

## Дальше
- точная настройка силы и длины оттягивания;
- эмоциональные подсказки «ещё один удар до УПАЙ»;
- инфопанель как в ORDO 20.72;
- автоигра;
- LMS-адаптер.
