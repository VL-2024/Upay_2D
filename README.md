# UPAY 2D v0.1.29-alpha

Отдельная 2D-версия игры УПАЙ.

## Что исправлено в v0.1.29-alpha
- исправлена геометрия удара: чуко-бита больше не летит в центр цели и не «замещает» её;
- бита останавливается перед целью в видимой точке контакта и остаётся там после удара;
- выбивается только целевой чуко: после контакта он плавно уходит по направлению удара за границу ковра;
- бита не участвует в вылете за ковёр;
- цвет и положение чуко-биты жёстко сохраняются при натягивании, отпускании, успешном ударе и промахе;
- при каждом новом билете 15 чуко распределяются по цветам 4/4/4/3; цвет с тремя экземплярами выбирается случайно, поэтому постоянных 6 синих больше нет;
- раскладка создаётся только в начале нового билета и не пересчитывается после удара.

## Правила
- одинаковый цвет/положение бьёт только такой же цвет/положение;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан выбивается отдельным финальным ударом в соответствующем сценарии.
