# UPAY 2D v0.1.22-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.22-alpha
- исправлена «мутность» цветных чуко: окраска теперь формируется через canvas-тон, а не тяжёлые CSS-фильтры;
- уменьшены glow и blur, контуры чуко стали резче;
- одинаковые положения чуко теперь алгоритмически разнесены по разным кольцам и секторам поля;
- одинаковые цвета также распределяются по полю более равномерно;
- приглушение неподходящих чуко стало мягче, без сильного «тумана»;
- панель «Положения чуко» сохранена и продолжает подсвечивать Айкүр / Таа / Бөк / Чик;
- цвет выбитого чуко сохраняется в ячейке УПАЙ;
- кнопка «БРОСОК / УДАР» и встроенное оттягивание/отпускание сохранены.

## Правила
- обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- одинаковое положение бьёт одинаковое положение.

## Уже есть
- встроенное оттягивание и отпускание;
- бьющий чуко летит к цели и после удара переворачивается в новое положение;
- подсветка допустимых целей;
- увеличенные цветные чуко;
- скрываемая панель положений;
- поля УПАЙ и сценарии ZERO / ONE / TWO / KHAN / ALTYN.
