# UPAY 2D v0.1.28-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.28-alpha
- полностью убраны старые runtime-перехваты движения из активной версии;
- чуко-бита теперь летит точно к выбранной цели и после удара остаётся в точке контакта;
- после натягивания и отпускания цвет/положение чуко-биты не меняются;
- выбитый чуко плавно вылетает за границу игрового ковра, но остаётся внутри экрана, делает паузу и затем по дуге улетает в УПАЙ;
- раскладка создаётся один раз в начале билета и больше не пересчитывается после ударов;
- начальная раскладка теперь действительно случайная, а не кольцевая;
- 15 обычных чуко распределяются почти поровну по четырём цветам: 4/4/4/3, причём цвет с тремя экземплярами выбирается случайно для каждого нового билета;
- размер обычных чуко немного уменьшен;
- используются только финальные цветные WebP-ассеты без программной перекраски.

## Цвета / положения
- Айкүр — синий;
- Таа — зелёный;
- Бөк — розовый;
- Чик — оранжевый.

## Правила
- одинаковое положение бьёт одинаковое положение;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- обычный билет продолжается до первого предусмотренного сценарием промаха.
