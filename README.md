# UPAY 2D v0.1.31-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.31-alpha
- механику удара перенёс на поведение из эталонной версии 20.72;
- использованы её базовые параметры столкновения: масса биты 1.7, масса обычного чуко 1.0, restitution 0.82;
- целевой чуко начинает двигаться в тот же кадр, когда бита входит в точку контакта — отдельной паузы после удара нет;
- после импульса целевой чуко проходит одну непрерывную one-shot траекторию к краю ковра;
- траектория выбитого чуко использует easeOutCubic, вращение и небольшую тангенциальную вариацию как в 20.72;
- конечная точка принудительно рассчитывается за видимой границей ковра, поэтому выигрышный чуко должен всегда пересекать край;
- бита после контакта остаётся в точке удара и не участвует в вылете;
- цвет и положение биты не меняются;
- раскладка создаётся только при новой игре, распределение цветов 4/4/4/3.

## Правила
- одинаковый цвет/положение бьёт только такой же цвет/положение;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан выбивается отдельным финальным ударом.
