# UPAY 2D v0.1.17-alpha

Отдельная 2D-версия игры УПАЙ.

## Что добавлено в v0.1.17-alpha
- Хана теперь нельзя просто нажать: его нужно именно выбить ударом чуко;
- при активации Хана игрок сначала выбирает чуко-биту;
- затем наводит сектор прицеливания на Хана и отпускает;
- прямой тап по Хану блокируется и показывает подсказку;
- Хан получает отдельную золотую подсветку и заметный отлёт после попадания.

## Что уже есть
- правило: обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ, 6 = 2 УПАЙ;
- четыре положения чуко: Айкүр, Таа, Бөк, Чик;
- бить можно только по чуко в том же положении;
- допустимые цели подсвечиваются, остальные чуко приглушаются;
- после удара бьющий чуко переворачивается и принимает новое положение;
- сектор прицеливания с градиентом и пунктирной осью;
- скрываемая панель «Положения чуко»;
- два поля УПАЙ по 3 ячейки;
- выбор ставки как в Чуко 20.72;
- разлёт чуко, удар, реакция соседних чуко и перелёт выбитого чуко в УПАЙ.
