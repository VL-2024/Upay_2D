# UPAY 2D v0.1.27-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.27-alpha
- выбитый чуко больше не улетает за край экрана: он вылетает только за границу игрового ковра и остаётся видимым;
- вылет после удара стал медленнее и плавнее;
- после короткой остановки за ковром выбитый чуко по дуге улетает в соответствующую ячейку УПАЙ;
- чуко-бита после удара больше не возвращается на исходное место: она остаётся в точке удара;
- положение и цвет чуко-биты после удара не меняются;
- раскладка чуко больше не пересчитывается после каждого удара;
- при новой игре чуко рассыпаются заново и заметно более случайно;
- размер обычных чуко немного уменьшен;
- нижний HUD и поля УПАЙ остаются закреплены относительно низа интерфейса.

## Правила
- обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- одинаковое положение бьёт одинаковое положение.
