# UPAY 2D v0.1.20-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.20-alpha
- логика снова собрана в одном `dom-main.js`, без конфликтующих игровых overlay-скриптов;
- прицеливание встроено непосредственно в основной игровой цикл;
- удар выполняется как в Чуко: выбрать биту → оттянуть назад → отпустить;
- направление удара противоположно направлению оттягивания;
- бьющий чуко заметно летит к цели;
- после удара бьющий чуко переворачивается и принимает новое положение;
- бить можно только по чуко в том же положении;
- сохранена скрываемая панель «Положения чуко» и подсветка Айкүр / Таа / Бөк / Чик;
- чуко увеличены;
- обычные чуко получили разные декоративные цвета: бирюзовый, лазурный, фиолетовый, коралловый, салатовый;
- цвет выбитого чуко сохраняется в ячейке УПАЙ;
- Хан также выбивается оттягиванием и отпусканием чуко-биты;
- центральная кнопка во время активного билета показывает «БРОСОК», после завершения — «НОВАЯ ИГРА».

## Правила
- обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- одинаковое положение бьёт одинаковое положение.
