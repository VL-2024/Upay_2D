# UPAY 2D v0.1.30-alpha

Отдельная 2D-версия игры УПАЙ.

## Что исправлено в v0.1.30-alpha
- чуко-бита теперь движется сама как один и тот же DOM-объект: больше нет клона, скрытия и визуальной подмены;
- бита летит по прямой точно к выбранной цели и останавливается в точке контакта перед ней;
- после короткого момента удара двигается только выбитый целевой чуко;
- чуко-бита остаётся в точке удара и не вылетает за ковёр;
- цвет, WebP-файл и положение чуко-биты жёстко сохраняются;
- выбитый чуко плавно уходит по направлению удара за видимую границу ковра и затем летит в УПАЙ;
- раскладка создаётся только при новой игре;
- 15 чуко распределяются по цветам 4/4/4/3, цвет с тремя экземплярами выбирается случайно.

## Правила
- одинаковый цвет/положение бьёт только такой же цвет/положение;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан выбивается отдельным финальным ударом.
