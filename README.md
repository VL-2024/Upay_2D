# UPAY 2D v0.1.32-alpha

Отдельная 2D-версия игры УПАЙ.

## Шаг 1–2: отдельный фон, отдельный ковёр и физика по реальному краю

- фон и ковёр теперь независимые слои;
- положение и размер ковра вынесены в настройки и не зависят от фона;
- центр и радиус раскладки чуко настраиваются отдельно от ковра;
- физика выбивания больше не использует условную жёстко заданную область;
- граница для вылета считывается прямо с DOM-слоя ковра;
- при перемещении или масштабировании ковра граница вылета меняется автоматически;
- используется v20.72-style удар: целевой чуко начинает реагировать в кадр контакта;
- выбитый чуко должен пересечь реальный край ковра и остаться видимым перед полётом в УПАЙ;
- бита остаётся в точке удара и сохраняет цвет/положение;
- обычные чуко слегка уменьшены;
- раскладка создаётся только в начале нового билета, цвета распределены 4/4/4/3.

## Настройки сцены

Параметры carpetCenterX, carpetCenterY, carpetWidth, carpetHeight,
pileCenterX, pileCenterY, pileRadiusX, pileRadiusY и edgeOutsetPx
находятся в src/config.js.

Для быстрой настройки из консоли доступны:
- UPAY2D.getSceneLayout()
- UPAY2D.setSceneLayout({...})

Следующий этап после визуальной проверки — точная подстройка высоты ковра, кучки и расстояния вылета.
