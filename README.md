# UPAY 2D v0.1.25-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.25-alpha
- подключены финальные цветные WebP-ассеты чуко без программной перекраски;
- Айкүр — синий, Таа — зелёный, Бөк — розовый, Чик — оранжевый;
- одинаковые положения по-прежнему разнесены по разным секторам поля;
- после удара чуко-бита больше не меняет положение и цвет: остаётся тем же чуко, выполняя только визуальный переворот;
- подсветка допустимых целей и панель «Положения чуко» сохранены;
- кнопка во время активной игры показывает «БРОСОК / УДАР»;
- удалены промежуточные старые JS-патчи и устаревшие ассеты.

## Правила
- обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- одинаковое положение бьёт одинаковое положение.

## Уже есть
- оттягивание и отпускание чуко-биты;
- полёт биты к цели;
- подсветка допустимых целей;
- скрываемая панель положений;
- поля УПАЙ и сценарии ZERO / ONE / TWO / KHAN / ALTYN.
