# UPAY 2D v0.1.16-alpha

Отдельная 2D-версия игры УПАЙ.

## Что добавлено в v0.1.16-alpha
- принято правило: обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ, 6 = 2 УПАЙ;
- для результатов 1 УПАЙ и 1 УПАЙ + 2/3 теперь требуется завершающий промах;
- добавлены четыре положения чуко: Айкүр, Таа, Бөк, Чик;
- бить можно только по чуко в том же положении;
- допустимые цели подсвечиваются, остальные чуко приглушаются;
- после удара бьющий чуко переворачивается и принимает новое положение;
- добавлен сектор прицеливания с градиентом и пунктирной осью;
- на мобильном можно вести сектор пальцем и отпускать его по подсвеченной цели;
- добавлена скрываемая панель «Положения чуко»; нажатие на Айкүр / Таа / Бөк / Чик подсвечивает соответствующие чуко на поле.

## Уже есть
- сценарный движок ZERO / ONE / TWO / KHAN / ALTYN;
- demo-режим по кругу;
- два поля УПАЙ по 3 ячейки;
- выбор ставки как в Чуко 20.72;
- текущая мобильная компоновка с фоном и ковром;
- разлёт чуко, удар, реакция соседних чуко и перелёт выбитого чуко в УПАЙ.
