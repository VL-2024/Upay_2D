## Что работает сейчас

- физика игрового поля переведена на **Matter.js 0.20.0**;
- чуко-бита летит к выбранной цели по псевдо-3D дуге;
- во время полёта бита проходит над промежуточными чуко и не сталкивается с ними;
- в момент контакта включаются обычные Matter.js-столкновения;
- выбиваемый чуко получает импульс сразу в кадр столкновения;
- бита после удара отскакивает, вращается и остаётся возле места контакта;
- соседние чуко могут физически сдвигаться и вращаться от вторичных столкновений;
- за границу ковра может выйти только выбранный выбиваемый чуко;
- остальные чуко удерживаются в пределах ковра даже при сильных вторичных столкновениях;
- Хан имеет отдельное физическое тело и до активации остаётся в центре;
- живые чуко больше не становятся полупрозрачными — подсказки делаются яркостью и свечением;
- стартовая раскладка не перестраивается после каждого удара;
- выигрышный чуко после выхода за край ковра перелетает в слот УПАЙ.

## Базовые настройки сцены

```json
{
  "chukoSize": 11.6,
  "khanSize": 15.2,
  "carpetSize": 82,
  "carpetTop": 46.6,
  "pileYOffset": -2.4,
  "pileHeight": 1.67,
  "scatterScale": 0.71
}
```

В панели настройки сцены можно менять размеры и положение элементов, создавать новую раскладку и копировать текущие параметры.

## Правила игры

- чуко бьёт только подходящий чуко того же положения/цвета;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан выбивается отдельным финальным ударом;
- сценарий результата задаётся игровой логикой, а Matter.js отвечает за физическое отображение удара и столкновений.
