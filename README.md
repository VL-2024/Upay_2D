# UPAY 2D v0.1.26-alpha

Отдельная 2D-версия игры УПАЙ.

## Что изменено в v0.1.26-alpha
- подключён финальный фон `upay_background_high_carpet.webp`;
- нижний HUD закреплён относительно низа экрана, поэтому поля УПАЙ больше не должны «плавать» при изменении масштаба браузера и высоты окна;
- после удара выбитый чуко теперь сначала вылетает по направлению удара за край ковра;
- на краю есть короткая пауза, затем чуко по дуге улетает в соответствующую ячейку УПАЙ;
- чуко-бита после удара сохраняет своё положение и цвет;
- финальные цветные WebP-ассеты остаются без программной перекраски.

## Правила
- обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ;
- 6 выбитых чуко = 2 УПАЙ;
- Хан — специальный финальный сценарий и также должен быть выбит ударом;
- одинаковое положение бьёт одинаковое положение.

## Уже есть
- оттягивание и отпускание чуко-биты;
- полёт биты к цели;
- выбивание цели за край ковра и последующий полёт в УПАЙ;
- подсветка допустимых целей;
- скрываемая панель положений;
- поля УПАЙ и сценарии ZERO / ONE / TWO / KHAN / ALTYN.
