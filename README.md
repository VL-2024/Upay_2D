# UPAY 2D v0.1.3-alpha

Отдельная 2D-версия игры УПАЙ на PixiJS.

## Что добавлено в v0.1.3-alpha
- сценарный движок, перенесённый по логике из 3D-прототипа;
- demo-режим по кругу: ZERO_B → ZERO_A → ONE → ONE_PLUS → TWO → KHAN → TWO_KHAN → ALTYN;
- игровые состояния для 1 УПАЙ, 1 УПАЙ + 2/3, 2 УПАЙ, ХАН и АЛТЫН;
- отдельный шаг неудачного последнего удара для ZERO_A / ZERO_B;
- активация Хана только в сценариях, где он нужен;
- выбор чуко-биты и затем чуко-цели;
- блокировка селектора ставки во время раунда;
- public hooks `window.UPAY2D.setScenario(...)`, `getScenario()`, `setDenominations(...)`.

## Запуск
```bash
python -m http.server 8080
```
Открыть `http://localhost:8080`.
