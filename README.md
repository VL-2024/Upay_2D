# UPAY 2D v0.1.18-alpha

Отдельная 2D-версия игры УПАЙ.

## Что добавлено в v0.1.18-alpha
- чуко увеличены примерно на 25%;
- прицеливание переделано по механике Чуко: выбрать биту → оттянуть её назад → отпустить;
- направление удара теперь противоположно направлению оттягивания;
- при оттягивании сама бита физически смещается за пальцем/мышью;
- впереди показывается градиентный сектор и пунктирная линия удара;
- допустимая цель дополнительно подсвечивается;
- прямой тап по цели больше не выполняет удар;
- Хан также выбивается только оттягиванием и отпусканием чуко-биты.

## Уже есть
- правило: обычный билет продолжается до первого промаха;
- 3 выбитых чуко = 1 УПАЙ, 6 = 2 УПАЙ;
- четыре положения чуко: Айкүр, Таа, Бөк, Чик;
- бить можно только по чуко в том же положении;
- подсветка допустимых целей;
- после удара бьющий чуко переворачивается и принимает новое положение;
- скрываемая панель «Положения чуко»;
- сценарии ZERO / ONE / TWO / KHAN / ALTYN;
- два поля УПАЙ по 3 ячейки.
